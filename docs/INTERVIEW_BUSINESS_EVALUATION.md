# 面试业务质量评测

## 目标

检索指标只能说明“资料是否被找到”，不能证明面试业务本身有效。本阶段对一场完整面试执行确定性质量审计，回答以下问题：

- 是否覆盖了面试蓝图中的核心能力；
- Critic 是否评价了每个有效回答；
- Plan Reviser 的动作是否被下一题正确执行；
- 问题是否重复、是否有知识库证据支撑；
- 最终报告引用的回答证据是否真实存在；
- 逐轮评分与最终评分是否出现明显冲突；
- 模型不可用时的降级比例是否过高。

## 版本与持久化

审计版本为 `business-quality-v1`，结果保存到 `interview_quality_audit`。同一场面试和同一审计版本只有一条记录，便于复现历史结果。删除面试时审计记录级联删除。

新评估报告完成后由 Celery 自动生成审计。历史报告可以调用：

```text
POST /api/v1/workspaces/{workspace_id}/interviews/{interview_id}/quality-audit
```

## 核心指标

- 有效作答率
- 计划能力覆盖率
- Critic 覆盖率
- 动态计划执行一致率
- 问题证据支撑率
- 问题重复率
- 报告证据有效率
- 报告证据覆盖率
- 报告维度完整性
- 逐轮评分与最终评分偏差
- 降级题目比例

## 质量门禁

每项指标保存实际值、阈值、是否通过和是否为强制项。强制项全部通过时，整场审计状态才为通过。题目少于 5 道或未触发动态计划时会产生样本量警告，避免对小样本结果过度解读。

该审计评价的是 AI 面试系统链路质量，不是替代企业对候选人的录用决策。
